BOLA UTAMA - SCOREBAT + LIVE HLS SETUP
=====================================

SCOREBAT / HIGHLIGHT
====================
Railway Variables:
SCOREBAT_TOKEN=<isi token ScoreBat Anda>
SCOREBAT_API_BASE=https://www.scorebat.com/video-api/v3/free-feed/
SCOREBAT_CACHE_SECONDS=300

Jika URL token berbentuk:
https://www.scorebat.com/video-api/v3/free-feed/?token=TOKEN_ANDA
maka masukkan hanya TOKEN_ANDA ke SCOREBAT_TOKEN.

Jangan gunakan token ScoreBat sebagai LIVE_FOOTBALL_API_KEY.
LIVE_FOOTBALL_API_KEY bersifat optional dan hanya diisi jika Anda memang memiliki key asli dari live-football-api.com.

LIVE STREAMING
==============
ScoreBat Video API v3 menyediakan video/highlight, bukan URL live HLS (.m3u8).
Live streaming pada project ini dikelola langsung melalui:
Admin -> Live Streaming -> Tambah -> isi URL Video HLS (.m3u8) -> Aktifkan.

RAILWAY PORT
============
Jangan membuat variable PORT=3000 di Railway.
Railway menyediakan process.env.PORT otomatis.
Project sudah memakai process.env.PORT || 3000 sehingga local development tetap bisa berjalan di port 3000.

ARSITEKTUR
==========
API-Football -> pertandingan/livescore/statistik
ScoreBat -> highlight/video
Admin HLS (.m3u8) -> live streaming
live-football-api.com -> optional fallback data, bukan streaming

Cek setelah deploy:
1. GET /health -> streamProvider harus "admin-managed".
2. GET /api/streams -> hanya stream aktif dari Admin yang muncul.
3. GET /api/diagnostics -> stream.provider harus "admin-managed".
4. GET /health -> scorebatReady harus true jika token ScoreBat diisi.
5. GET /api/highlights -> provider menjadi "scorebat" saat feed ScoreBat tersedia.
6. Buka /highlights untuk katalog highlight.
7. Buka /livescore?tab=live untuk daftar live stream HLS yang sudah diaktifkan Admin.

PLAYER SCOREBAT
- Highlight: otomatis dari SCOREBAT_API_BASE dan diputar langsung di website.
- Live: hanya item ScoreBat yang benar-benar ditandai LIVE/in-play dan punya embed.
- Endpoint free-feed ScoreBat umumnya menyediakan video/highlight; jangan menganggap semua item sebagai live streaming.
- HLS Admin tetap tersedia sebagai fallback jika ScoreBat tidak menyediakan live embed.
